FOUR MORE DEFECTS FOUND (Phase 1's four fatal fixes were NOT sufficient)
================================================================================
  The Phase-1 end state — all four fatal defects fixed — still produced FID 206.49.
  Pilot (10 epochs each, N=2048/seed 42, diagnostic only):

    A  legacy precond, sigma_max=1.0    FID = 206.49   <- Phase-1 end state
    B  legacy precond, sigma_max=42     FID = 116.87   <- +sigma_max fix   (-43%)
    C  edm precond,    sigma_max=42     FID =  74.70   <- +precond fix     (-36%)

  E. sigma_max=1.0 was ~42x TOO SMALL for a valid VE prior.
     Song technique-1: sigma_max = max pairwise training distance. MEASURED on
     FashionMNIST in [-1,1]: 41.88. At sigma_max=1.0 the perturbed distribution still
     retains almost all data structure, so the N(0,sigma_max^2) init is not the prior.
     FIXED: sigma_max=42.0. Requires the retrain — the old model never saw sigma>1.

  F. THE DSM OBJECTIVE WAS UNWEIGHTED.
     target=-eps/sigma has magnitude 1/sigma, so the loss scale goes as 1/sigma^2: a 1e4
     ratio over [0.01,1] and 1.7e7 over the corrected [0.01,42]. The gradient collapsed
     onto the smallest sigmas; the large-sigma regime — where the reverse trajectory
     STARTS — was barely learned.
     FIXED: dsm_weighting="sigma_sq" (equivalent to eps-prediction, O(1) at every sigma).
     A convention guard now RAISES if "none" is used with a >100x sigma range.

  G. THE MODEL'S PRECONDITIONING WAS BADLY CONDITIONED.
     h = x/sigma makes the network input span 70x across sigma in [0.01,42] — worst at
     the low-sigma end, where sample quality is decided.
     FIXED: EDM preconditioning (Karras et al. 2022), input held at unit scale for every
     sigma. VERIFIED: with F=0 the branch reduces to the exact analytic Gaussian score to
     0.00e+00 relative error across four decades of sigma.
     SUB-FIX: the literal Tweedie form (c_skip*x - x)/sigma^2 suffers CATASTROPHIC
     CANCELLATION at small sigma (measured 2.959e-03 abs error at sigma=0.01, float32).
     Since c_skip-1 = -sigma^2/(sigma^2+sd^2) EXACTLY, sigma^2 cancels analytically:
     score = -x/(sigma^2+sd^2) + (c_out/sigma^2)*F. Identical algebra, 0.00e+00 error.

  H. THE EMA HAD NO BIAS CORRECTION.  *** the subtlest one ***
     `shadow` was seeded with the RANDOM INITIALISATION and decayed at 0.9999 with no
     correction, so the weight remaining on the init is decay^t:
         epoch  10 -> 80.0% still random init
         epoch  50 -> 32.8%
         epoch 100 -> 10.8%
     MEASURED at epoch 10:  RAW weights FID 99.75  |  EMA weights FID 373.07
     The "EMA" checkpoint was mostly noise. A FID-vs-epoch curve built on it would have
     measured how fast the EMA forgets its initialisation, not how fast the model learns
     — and would have looked like a perfectly plausible learning curve.
     FIXED: warmup schedule decay_t = min(decay, (1+t)/(10+t)). VERIFIED: with the model
     pinned at 10.0 from step 1, old EMA reads 1.9989 (80% init) at 2230 updates; new
     reads 10.0000 (0.0000% init).
     LIMITATION: the contaminated shadow already saved in these checkpoints CANNOT be
     recovered post hoc (it needs theta_init, which is not saved). Gate 2.2 is therefore
     evaluated on RAW weights — simply the trained model, and perfectly valid.

  I. FID WAS COMPUTED ON INVERTED IMAGES [non-fatal].
     FrechetInceptionDistance(normalize=True) was fed uint8. torchmetrics does
     `imgs = (imgs*255).byte() if normalize`, so uint8 WRAPS MOD 256: pixel v -> (256-v).
     HONEST SCOPING: both real and fake got the same transform, so FID stayed a valid
     distance — this is NOT why the pre-audit FIDs were ~326 (that was sampler defect A1).
     But it computed FID in an inverted pixel space, so the project's numbers are not
     comparable to published FashionMNIST FIDs, which the paper requires.
     Measured on identical inputs: 18.92 (bug) vs 20.79 (correct). FIXED: normalize=False.
     InceptionScore(normalize=True) is CORRECT (fed float [0,1]) and was left alone.

  J. simulate_path initialised at N(0,I), not the VE prior N(0, sigma_max^2).
     Only correct when sigma_max==1; with sigma_max=42 it would start the controller's
     rollout ~42x too close to the origin. FIXED.

  RUNNING TOTAL: 8 defects fixed (4 fatal in Phase 1 + 4 more in Phase 2), plus 2 non-fatal.
