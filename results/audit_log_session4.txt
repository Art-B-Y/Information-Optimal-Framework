CATEGORY 3 — NUMERICAL STABILITY
=============================================================

CAT3-1 FIX: score_unet.py ScoreUNet.forward() — sigma not clamped.
  Bug: h = x / sigma and return score / sigma — if sigma reaches 0.0 (e.g.
       at the very end of a diffusion trajectory where t→0), these operations
       produce NaN/Inf. sigma_t at t=eps≈1e-3 is finite but near zero.
  Fix: Added sigma = sigma.clamp(min=1e-5) before the first division.
       This prevents NaN without materially affecting training at normal sigma values.
  Files changed: src/its/models/score_unet.py

CAT3-2 FIX: conversions.py eps_to_score() — unguarded division by sigma.
  Bug: return -eps / sigma — if sigma=0 is passed, produces NaN.
       Used primarily in test code and exported API but should be robust.
  Fix: Added sigma = sigma.clamp(min=1e-5) before division.
  Files changed: src/its/sde/conversions.py

CAT3-3 FIX: fluctuation.py jarzynski_work_estimate() — dead code.
  Bug: Variable `log_z` was computed (m + log(mean(exp(...)))) but never
       used. Left from a prior refactor of the logsumexp implementation.
       The actual return path correctly uses `log_mean_exp` computed from `lse`.
  Fix: Removed the dead `log_z` line. Added clarifying comment explaining
       the LogMeanExp derivation.
  Files changed: src/its/physics/fluctuation.py

Additional checks (no fix needed):
  - SinusoidalTimeEmbedding.forward(): at t=0 produces [0,...,0,1,...,1] (no NaN).
    At t=1, sin/cos of moderate values, all finite. Safe.
  - _FiLMLayer: scale+shift are linear operations on bounded time embedding. Safe.
  - DSM loss: sigma is always > 0 from log-uniform sampling (exp of finite number).
    target = -noise/sigma: safe since sigma_min=0.01.
  - Girsanov log-RN: can produce large values for large control, but
    jarzynski_work_estimate applies max_clip to prevent overflow in exp(). Safe.
