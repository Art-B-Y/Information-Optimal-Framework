The ITS Framework

ITS learns a control drift uθ(x,t) that is added on top of a pretrained VP-SDE score model to steer the reverse diffusion trajectory toward a more efficient or higher-quality distribution. The controlled reverse SDE is:

dx = [f(x,t) + g²(x,t) sθ(x,t)] dt + uθ(x,t) dt + g(x,t) dWt

where f, g are the VP-SDE drift and diffusion coefficients, sθ is the learned score (pretrained and fixed), and uθ is the trainable controller. The controller is trained jointly on five objectives:

  1. DSM loss — denoising score matching to keep the base model accurate
  2. Path-KL — Girsanov log-RN between controlled and free path measures
  3. Control energy — L² regularisation: ‖uθ‖²
  4. Feature matching — mean Inception feature L² distance (quality heuristic)
  5. Jarzynski estimator — free-energy ΔF from work samples along trajectories

7. Information-Theoretic Analysis

The Path-KL Term and Girsanov's Theorem

In the ITS framework, the controller uθ defines a new measure Pu on path space that differs from the reference measure P0 induced by the uncontrolled SDE. The KL divergence between these two path measures is given by the Girsanov theorem:

KL(Pu ‖ P0) = EPu [ log dPu/dP0 ] = E [ ½ ∫₀ᵀ ‖u(x_t, t)/g(x_t, t)‖² dt ]

The log Radon-Nikodym derivative log(dPu/dP0) can be approximated along discrete-time trajectories using Euler-Maruyama steps as:

log RN ≈ ∑_k [ u_k · ΔW_k / g_k − ½ ‖u_k/g_k‖² Δt ]

where ΔW_k = W_(k+1) − W_k is the Wiener increment at step k. This is the quantity the ITS training objective attempts to minimise (weighted by λ_kl). In the training logs, this quantity starts at ~53 and decreases to ~5 over the first two epochs, indicating the controller is learning to stay close to the reference measure while still influencing the trajectory.

The Jarzynski Equality and Free-Energy Estimation

The Jarzynski equality is a non-equilibrium thermodynamic identity that connects the irreversible work W done along a stochastic trajectory to the equilibrium free-energy difference ΔF:

Etrajectories[exp(−βW)] = exp(−βΔF)

In the diffusion context, W is the accumulated work done by the control drift against the noise: W ≈ ∑_k u_k · (x_(k+1) − x_k − f_k Δt) / g_k². Taking the log of both sides and using the numerically stable log-sum-exp formulation:

ΔF = −(1/β) log[ (1/N) ∑_i exp(−β W_i) ] = −(1/β) [ logsumexp(−β W) − log N ]

The ITS implementation clips extreme work values at |W| ≤ max_clip=50 before exponentiation to prevent numerical overflow — this was Bug 6, now fixed. The Jarzynski estimator is biased for small N (Jensen's inequality), so large trajectory batches are needed for reliable ΔF estimates. Current training uses N=batch_size per mini-batch, which gives high-variance estimates; a dedicated evaluation pass with N≥1000 trajectories would give a more reliable free-energy estimate.

Information Cost of Generation

The path-KL term has a direct information-theoretic interpretation: it measures how many nats of information the controller "spends" per generated sample to deviate the trajectory from the reference SDE. A controller that achieves lower FID with lower path-KL achieves a more information-efficient improvement. Conversely, a high path-KL with no FID improvement indicates the controller is spending information budget without improving quality — the regime the current λ_kl=0.1 regularisation is designed to prevent. The goal is to find the Pareto frontier in the (path-KL, FID) trade-off space.

8. Current Limitations and Honest Assessment

  1. The controller has not yet been demonstrated to improve FID over DDPM/DDIM baselines.
    All evaluation in this session used 3-epoch CPU-trained checkpoints with N=256 samples — insufficient for statistical conclusions. Addressing this requires training to 50+ epochs on GPU with N≥5000 evaluation samples.
  2. The feature-matching quality term is a heuristic approximation, not a true distribution-level objective.
    Computing the L² distance between batch mean Inception features is a first-order moment matching that ignores second-order statistics (captured by FID's covariance term). A more principled objective would be a kernel MMD or a full FID-style loss — but these require large batches to estimate stably.
  3. Evaluation has been conducted on small sample counts; results are not statistically reliable.
    FID with N=256 typically has ±30–80 standard deviation depending on the model. The FID difference between DDPM (360.9) and DDIM (375.2) is within this noise range. At least N=5000 is required for FashionMNIST and N=10000 for CIFAR-10.
  4. The CIFAR-10 score model was trained for 50 epochs, which is insufficient for high-quality generation.
    State-of-the-art CIFAR-10 diffusion models require 500–1000+ epochs. The current model produces structurally recognisable but blurry images. Re-training from scratch with the same architecture for 200 epochs would bring FID into the 15–30 range.
  5. The Schrödinger bridge IPF solver is a research skeleton; end-to-end convergence has not been validated.
    SchrodingerBridgeSampler in src/its/samplers/sb_solver.py implements the IPF Girsanov path-KL loss and alternating train_step_forward / train_step_backward gradient steps using ConvControlPolicy for both directions. Shape tests pass (see test_schrodinger_bridge_shapes), but multi-iteration IPF convergence requires GPU-scale training that is out of scope for the current CPU-only experiments.
  6. Thermodynamic quantities are computed approximately; the Crooks fluctuation theorem has not been formally verified.
    The Jarzynski estimator uses the Euler-Maruyama discretisation, which introduces a time-step bias in the work estimates. Formally verifying the Crooks theorem (detailed balance condition) would require running the time-reversed SDE and comparing forward/backward work distributions — a non-trivial experiment not yet implemented.
